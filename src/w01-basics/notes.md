### D2 课前小测（先作答，不运行代码）

> 这一组题用于检查运算符、表达式求值、短路逻辑和循环控制的前置直觉。先写答案，再读后面的讲解总结。

**T1：`byte b = 1; b += 1;` 能编译，而 `b = b + 1;` 不能。为什么？**
我的答案：复合赋值隐含类型转换，把 int 窄化；直接赋值不做这种隐式窄化。
教师核对：正确。`b += 1` 可理解为 `b = (byte)(b + 1)`；`b = b + 1` 的右边是 int，不能直接赋给 byte。

**T2：`obj != null && obj.isValid()` 中，如果 `obj` 是 null，右边会不会执行？为什么？**
我的答案：不会执行；`&&` 左边的条件为假时，整个表达式已经确定为假。
教师核对：正确，这是短路求值。`&` 不是短路运算符，会计算两边。

**T3：`-1 >> 1` 和 `-1 >>> 1` 的结果分别是什么？区别来自哪里？**
我的答案：`-1 >> 1` 是 -1；`-1 >>> 1` 是 32 位的 `01111...`。区别是算术右移补符号位，逻辑右移补 0。
教师核对：方向正确。`-1 >>> 1` 的完整结果是 `2147483647`，二进制为 `01111111 11111111 11111111 11111111`。

**T4：传统 `switch` 的某个 `case` 忘记写 `break`，会发生什么？**
我的答案：死循环。
教师核对：不正确。漏写 `break` 会发生 case 贯穿（fall-through），继续执行后面的 case 语句，直到遇到 `break` 或 switch 结束；它本身不会造成死循环。

**T5：`while` 和 `do-while` 在“最少执行次数”上有什么区别？**
我的答案：分别是 0 和 1 次。
教师核对：正确。`while` 先判断后执行；`do-while` 先执行一次，再判断。

**T6：`i++` 和 `++i` 都会让 `i` 增加 1，它们作为表达式时有什么不同？**
我的答案：前者的值是 i，后者是 i+1。
教师核对：正确。`i++` 返回增加前的值，`++i` 返回增加后的值；两者都会修改 i。

**T7：`5 / 2`、`-5 / 2`、`-5 % 2` 分别是什么？**
我的答案：未作答。
教师核对：分别是 `2`、`-2`、`-1`。整数除法向零截断，余数符号跟被除数一致。

### D2 讲解总结

表达式会产生一个值，语句表示一个执行动作。运算符先按优先级和结合性分组，再按操作数规则求值；复杂表达式应主动加括号。

整数除法向零截断，取余结果跟被除数同号。`&&` 和 `||` 具有短路求值，`&` 和 `|` 不短路；位运算和移位直接操作二进制位，`>>` 复制符号位，`>>>` 在高位补 0。

`switch` 的传统 `case` 会贯穿，漏写 `break` 会继续执行后面的分支；箭头语法不会贯穿。循环分为 `for`、`while`、`do-while`，`while` 最少执行 0 次，`do-while` 最少执行 1 次；`break` 结束当前循环，`continue` 跳过本轮剩余部分。

调试器用于观察程序的实际状态：断点暂停执行，Step Over 不进入方法，Step Into 进入方法，Step Out 返回调用方；Variables、Watches 和 Evaluate Expression 用来检查变量与表达式。

## D3 数组

### D3 课前小测（先作答，不运行代码）

> 这一组题用于检查“引用语义、数组默认值、二维数组和二分查找”的前置直觉。先写答案，再读后面的讲解总结。

**T1：`int[] a = {1, 2, 3}; int[] b = a; b[1] = 9;` 此时 `a[1]` 是什么？**
我的答案：9
教师核对：正确。`b = a` 复制的是引用值，两个变量指向同一个数组对象；`b[1] = 9` 修改的是这个共享对象，所以 `a[1]` 也是 9。

**T2：`int[] a = {1, 2}; int[] b = {1, 2};` 此时 `a == b` 是什么？**
我的答案：false
教师核对：正确。`==` 比较引用身份；两个 `new` 出来的数组是两个不同对象，即使内容相同也不相等。要比较内容用 `Arrays.equals(a, b)`。

**T3：`new int[3]` 创建后，三个元素的默认值是什么？**
我的答案：0?
教师核对：正确。`int` 数组元素默认值是 0；完整默认值表：数值类型是 0/0.0，`char` 是 `'\u0000'`，`boolean` 是 `false`，引用类型是 `null`。

**T4：数组的 `length` 可以修改吗？数组长度可以动态增加吗？**
我的答案：不知道，猜测可以
教师核对：不正确。`length` 是只读的，创建后固定；数组不能原地变长。需要更多空间时，只能创建新数组并复制旧元素（`Arrays.copyOf` / `System.arraycopy`），再让引用指向新数组。`ArrayList` 的“扩容”本质也是这个动作。

**T5：`int[][] a = new int[2][3];` 中，`a.length` 和 `a[0].length` 分别是什么？**
我的答案：2,3
教师核对：正确。`int[][]` 是“数组的数组”：外层长度 2，每个元素是一个长度为 3 的 `int[]`。

**T6：二分查找在开始前必须满足什么条件？如果数组没有排序，会怎样？**
我的答案：不知道
教师核对：二分查找要求数组已经按比较规则排好序（通常是升序）。未排序时，不能根据 `a[mid]` 判断目标在左半还是右半，继续缩小范围的前提不成立，结果不可靠；`Arrays.binarySearch` 也要求调用前已排序。

**T7：`Arrays.asList(new int[]{1, 2, 3}).size()` 的结果是多少？**
我的答案：不知道
教师核对：结果是 1。`Arrays.asList` 的签名是 `<T> List<T> asList(T... a)`；传入 `int[]` 时，`T` 被推断为 `int[]`，整个数组成为可变参数数组里的一个元素，而不是三个 `Integer`。换成 `Integer[]` 才会得到 3 个元素。

**Q9：数组的内存布局长什么样？为什么 `length` 不是普通字段、不能修改？**
A：数组是对象，变量保存的是引用。HotSpot 中一个数组对象可以理解为由对象头、长度信息和连续的元素区域组成；语言层面通过只读的 `length` 字段暴露长度，JVM 通过 `arraylength` 指令读取，长度在创建时固定，不能通过 Java 代码重新赋值。下标访问是 `base + i * elementSize` 的直接寻址，运行时还要做边界检查，越界会抛 `ArrayIndexOutOfBoundsException`。

**Q10：`Arrays.asList(new int[]{1,2,3})` 返回的 list 有几个元素？为什么？**
A：1 个。`Arrays.asList` 是泛型可变参数方法 `asList(T... a)`，传入 `int[]` 时，整个 `int[]` 被看成一个 `T` 对象，而不是三个 `Integer` 元素；如果要得到三个元素，应使用 `Integer[]`，或先把基本类型数组转换成对象流。`Arrays` 是 `java.util` 包中的工具类。

**Q11：二分查找的循环条件是 `low <= high` 还是 `<`？写错会漏掉什么场景？**
A：在闭区间 `[low, high]` 中应使用 `low <= high`。如果写成 `<`，当区间只剩一个元素时会提前退出，可能漏掉目标值。二分查找的前提是数组已按同一顺序排好；每次比较中间元素后，只保留可能包含目标的那一半。中间下标应写成 `low + (high - low) / 2`，避免 `low + high` 溢出。比较完 `a[mid]` 后要排除 `mid`，所以是 `low = mid + 1` 或 `high = mid - 1`；写成 `low = mid` 可能死循环。有重复值时，普通二分只保证返回某个匹配位置，不保证第一个或最后一个。

### D3 讲解总结

一句话主线：**数组变量保存引用，数组对象是定长的连续元素块。**

数组是对象，不是“一组变量的语法糖”。局部变量 `a` 里存的是指向数组对象的引用；对象本身由对象头、长度和连续元素区组成。`a.length` 在语言层面只读，JVM 用 `arraylength` 读取；下标访问有运行时边界检查，越界抛 `ArrayIndexOutOfBoundsException`。长度在创建时固定，因为元素按 `base + i * size` 连续寻址，原地变长会破坏布局和对象身份；需要扩容只能新建数组并复制。

`b = a` 复制引用值，两个变量别名同一个对象；`b[1] = 9` 对 `a` 可见。`a == b` 比较身份，内容比较要用 `Arrays.equals`；数组没有重写 `equals`，所以 `a.equals(b)` 仍然是比较身份。方法传数组时传的是引用副本：改元素可见，重新赋值参数不可见，这仍然是值传递。

二维数组是“数组的数组”：`int[][] a = new int[2][3]` 的外层长度是 2，每个元素是一个长度为 3 的 `int[]`；`new int[2][]` 只创建外层，行还是 null。行可以不等长，所以遍历时用 `a[i].length`。

排序把元素按规则重排，是二分查找的前置条件。`Arrays.sort(int[])` 对基本类型排序；对象数组要求 `Comparable` 或传 `Comparator`。二分查找在闭区间 `[low, high]` 内工作，循环条件必须是 `low <= high`；`mid = low + (high - low) / 2`，比较后排除 `mid`，所以是 `low = mid + 1` 或 `high = mid - 1`。未排序时不能二分；有重复值时只保证找到某个匹配位置，不保证第一个或最后一个。

`Arrays` 是 `java.util` 的工具类：`toString`/`deepToString`、`sort`、`copyOf`、`fill`、`equals`/`deepEquals`、`binarySearch`、`asList`。`asList(T... a)` 传入 `int[]` 时会把整个数组当成一个元素，`size()` 为 1；返回的是固定大小视图，`set` 可以写回原数组，`add`/`remove` 抛 `UnsupportedOperationException`。

### D3 必须能说出的三句话

1. 数组变量是引用，数组对象定长；别名改元素可见，改引用不可见。
2. 数组不能原地扩容，扩容 = 新数组 + 复制 + 重定向引用。
3. 二分查找的前提是有序；闭区间用 `low <= high`，排除 `mid` 用 `mid ± 1`。

### D3 常见误区

- `i <= a.length` 会越界，合法下标是 `0 .. a.length - 1`。
- 数组用 `length`（字段），String 用 `length()`（方法），集合用 `size()`。
- `a == b` 比身份；`a.equals(b)` 对数组仍然比身份；比内容用 `Arrays.equals`，嵌套数组用 `Arrays.deepEquals`。
- `new String[3]` 的三个元素都是 `null`，直接调用元素方法会 `NullPointerException`。
- `new int[2][]` 只分配外层，`a[0]` 还是 `null`；要先给每一行分配数组。
- `Arrays.asList(new int[]{1,2,3})` 的 `size()` 是 1；换成 `Integer[]` 才是 3。
- 二分查找前没排序，结果没有意义；`while (low < high)` 会漏掉只剩一个元素的场景；`low = mid` 可能死循环。
- `final int[] a` 只表示引用不能改指向，元素仍然可以修改。
