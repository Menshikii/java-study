## 踩过的坑

- 现象：终端里 `java -version` 输出 1.8.0_503，`javac` 直接报「不是内部或外部命令」
- 原因：`C:\Program Files (x86)\Common Files\Oracle\Java\java8path` 与 `javapath` 两条**系统** PATH 条目排在解析链最前面，且系统 PATH 永远先于用户 PATH；该目录只有 `java.exe`（JRE），没有 `javac.exe`
- 解决方式：装 JDK 21 → 在**系统变量**里删掉这两条 Oracle 条目 → 新建 `JAVA_HOME` 并加 `%JAVA_HOME%\bin`
