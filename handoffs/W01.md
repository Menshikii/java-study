## 每天的「原理 1.5h」做什么（这是面试真正加分的地方）

| 天 | 源码 / 字节码实验 |
|---|---|
| D1 | `javap -c -p` 看自动装箱（`Integer.valueOf`）、读 `java.lang.Integer.IntegerCache` 找 -128~127 的来源 |
| D2 | `switch` 的字节码（`tableswitch` vs `lookupswitch`）、`>>` 与 `>>>` 在字节码里的差异 |
| D3 | 数组的内存布局（对象头 + length + `[I` 描述符）、`Arrays.sort` 的双轴快排入口、越界异常从哪抛 |
| D4 | 重载绑定优先级（基本类型 → 装箱 → 可变参）、`invokestatic`/`invokevirtual` 与静态/动态绑定、递归栈帧实测 |
| D5 | 字符串常量池 + `intern()`、String 不可变性与紧凑字符串、循环拼接编译成什么（`invokedynamic` / `StringConcatFactory`） |
| D6 | 读写四种访问修饰符的可见性边界（用真实编译错误验证）、`static` 成员的初始化时机 |
